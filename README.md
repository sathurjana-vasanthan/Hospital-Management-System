# 🏥 Hospital Management System

### Python | Tkinter | Object-Oriented Programming

## 📌 Project Overview

The Hospital Management System is a desktop application
developed using Python.

The project demonstrates the application of software
development concepts to hospital administration.

- Python
- Tkinter
- Object-Oriented Programming (OOP)
